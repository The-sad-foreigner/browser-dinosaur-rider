# browser-dinosaur-rider
Долгое приключение наездника на динозавре из браузера  
Это игра является похожей на браузерного динозаврика, но с видом сверху и без прыжков.  
Вы будете уворачиватся от кактусов.  
Это будет проверка на вашу реакцию,  
Данная игра будет в случайном порядке устонавливать преграды,  
Токже в дань уважения к браузерному динозавру,  
Со временем будет увеличиватся скорость игрока.  
## Желаю всем удачного заезда!
